# ipatool webGUI demo

Это статическая демонстрационная копия интерфейса ipatool GUI. Все ответы API подменяются в `demo-api.js`, поэтому Apple ID и реальное скачивание IPA не требуются.

Для просмотра локально:

```bash
python3 -m http.server 8080 --directory docs
```

На GitHub Pages каталог `docs` публикуется workflow-ом `.github/workflows/pages.yml`.

В массовой загрузке можно вставить несколько строк и последовательно просмотреть процесс проверки и загрузки. Все тестовые приложения завершаются успешно.
