# ipatool webGUI demo

Это статическая демонстрационная копия интерфейса ipatool GUI. Все ответы API подменяются в `demo-api.js`, поэтому Apple ID и реальное скачивание IPA не требуются.

Для просмотра локально:

```bash
python3 -m http.server 8080 --directory docs
```
Тексты интерфейса лежат в `assets/locales/` — по одному JSON-файлу на язык
(`ru.json`, `en.json`) плюс `index.json` со списком языков и языком по умолчанию.
Демо использует те же правила выбора языка, что и GUI: сохранённый выбор →
язык браузера → значение `default` из `index.json`.
